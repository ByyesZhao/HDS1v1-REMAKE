# HDSI V0.5：网页搜索

日期：2026-10-09。返回[总架构](../architecture/REMAKE_V0.5.md)。搜索是共用能力模块，各逻辑模型阶段拥有独立资格、正文集合与计数。

## 1. 接入状态

已实现可替换的“搜索候选→读取正文”接口、模型工具协议、独立会话、额度、缓存、失败／不足反馈和恢复记录。当前没有选择实际供应商，正式配置关闭搜索；启动入口拒绝只打开开关而不装配供应商。

正式入口已装配搜索服务，模型阶段也会建立会话记录；当前供应商不可用且开关关闭，因此工具不向模型开放。服务装配、会话记录与实际联网是不同状态。

因此“任何阶段可搜索”是接线完成后的能力范围，不代表现运行已实时联网。旧配置网页列表不自动提供搜索候选或兜底；不能用它伪装开放搜索。

该接口不依赖DeepSeek原生搜索：模型通过已有JSON工具合同提出查询或读取请求，HDSI调用供应商并把结果返回同一模型阶段。Flash可以沿此路径使用外部搜索。当前配置只有开关与额度，没有供应商选择、端点及搜索密钥装载字段；仍需实现适配器并接入正式装配后才能启用。候选方案见[模型调用与搜索服务参考](../reference/MODEL_CALLS_AND_WEB_OPTIONS_20261009.md#4-网页搜索接入建议)。参考中的供应商均未在本项目实际接入或认证测试。

后续成本优先选择已形成[本地浏览器搜索待审计划](../plans/image-input-local-search-20261009/README.md)，建议适配旧项目公开页面端口；不是已实现功能，不需购买API但仍依赖外部搜索网站、网络及本机浏览器。当前开关和供应商状态不变。

## 2. 谁可以使用

普通／共同主叙事，聊天／生活／共同个人导演，表达，基础记忆，深度整理／审核，世界，校园／课题组／周阶段以及素材描述均可在已启用且需资料时使用。没有必需通知而免调用的周阶段当然不额外搜索。

程序限制提供给阶段的资料可见范围；查询文字由模型生成并传给供应商，提示要求只用该阶段已可见信息，当前没有逐词检查查询的程序过滤器。表达搜索只核验／润色既定内容；维护搜索不能扩大正式记忆来源。网页正文始终是外部参考，不是改职责的指令。

## 3. 20成功／40失败口径

一次逻辑任务会话最多20次成功取得正文、40次失败，分开计数，任一达到上限停止新操作。不是每发一个搜索请求就重置20／40，也不是单个HTTP请求最多20页。

同一阶段的格式修补、本地查询续调用、多个搜索／读取调用和恢复共用原计数。下一阶段、下一故事轮或新的独立后台任务有自己的额度。计数表示取得页面材料和失败步骤，不是费用或网络调用总数。

- 成功：该阶段首次取得一份有效正文，包括首次从本轮公共缓存取得；同阶段重用同一页面不再加1。
- 失败：搜索异常、没有候选、非法候选URL、正文读取异常或空正文等；分别累计，不占成功额度。
- 失败未到40且成功未到20，可继续尝试其他候选或新查询。
- 达到失败40，即使成功不足20也停止；达到成功20同样停止。

候选列表去重复后逐页尝试。搜索请求可以要求多个成功页面，失败继续补尝试直到满足、候选耗尽或到限；不能以“一页失败”为由禁止剩余额度内继续查询。

## 4. 缓存B

本轮／同一任务主体可以复用公开页面缓存以减少实际网络读取，但阶段额度仍独立。同页在主叙事、个人、表达、记忆阶段各首次取得，会各计一次成功。一个实际抓取可对应多个阶段成功取得记录。

这是已确认的B口径：“每阶段能读多少页”，不是“每轮访问网络多少次”。状态同时记录缓存命中、供应商搜索次数和读取次数，避免把成功额度当HTTP收费数。

同一阶段重放已确认操作不重复计数。缓存不是本进程全局免费资源；任务结束释放该主体缓存，已保存阶段资料仍支持恢复。

## 5. 结果不足与未知

返回实际成功正文、要求／取得页数、累计计数和停止原因。少于要求时明确传回“结果不足”，不伪造资料或自动改用未配置网页。

模型可根据已有材料完成工作、保留未知或继续额度内查询。对话个人导演可以自然向用户询问，角色不必每个问题都得出确定答案。额度耗尽后收回工具，要求用当前材料输出自身合法结果。

正文去除明显页面框架后作为完整正文提供，没有12000字／网页token人工截断。页面数量有限仍可能撞模型实际容量；超限按报错保留，不自动摘要或删资料。

## 6. 实际提供与本人阅读

取得正文与成功提供给模型是两步。只有接口成功返回、相关正文确实进入该阶段后，才登记已提供；失败请求不谎称读过。

世界／学校可引用URL限定为其实际提供正文的地址，不从候选标题、查询或模型臆造链接中建立引用。报道和不确定内容保留其性质。

只有自主生活个人导演的实际提供产生本人查阅来源，可记录“我查到……”类短期及有依据感受，单独引用它无需新用户聊天。仅此来源不能变更私人细节或唤醒长期，也不能把网页中的他人事件写成亲历。

聊天／共同个人导演目前没有同等独立本人查阅登记；它们实际产生的正常公开输出或主叙事经历仍可作为普通记忆来源。不能概括成“所有个人导演搜索直接写入记忆”。

## 7. 中断与恢复

阶段、操作、已确认页、计数及模型工具检查点持久保存。中断后同一阶段接续，已确认步骤不重计；未确认操作可能重新执行，不能保证供应商实际请求绝对一次。

已经冻结剧情／发送的恢复不重新搜索来改稿。未发送重生成可以重新生成业务内容，但仍沿用同阶段工具进度和权限。阶段完成后压缩检查点，保留需要的来源与统计。后台维护准备失败／停止保留完整阶段进度，只有最新持久任务 ready／done 才压缩，见[恢复§7](REMAKE_V0.5_RECOVERY.md#7-后台记忆恢复)。

实际供应商在线延迟、读取质量和费用尚未验收；离线接口测试不代表这一部分已经上线。

## 8. 状态展示

普通状态使用SQL历史汇总及当前最多3个任务、每任务6个阶段，展示各会话自己的20/40额度。后台整理及环境准备／待提交步骤也作为当前任务；状态不读正文、输入和checkpoint，不删除历史。网页状态通过有限条目与标签长度保持摘要有界，2048字符是该网页摘要的验收上限；完整诊断保留精确计数。环境跨generation继续用同一step owner和generation阶段键，保留累计计数、操作与材料；本地补查请求及pending状态可持久接续，实际返回依据与结果一起确认。它不是页面正文或模型输入预算，也不约束其他状态栏目。历史SQL汇总仍可能随会话数量增长，未新增全局持久计数缓存。
