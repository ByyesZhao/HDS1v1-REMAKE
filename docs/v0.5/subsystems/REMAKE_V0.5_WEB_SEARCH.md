# HDSI V0.5：网页搜索

核对日期：2026-10-11。返回[总架构](../architecture/REMAKE_V0.5.md)。搜索是共用能力模块，各逻辑模型阶段拥有独立资格、正文集合与计数。

## 1. 接入状态

已实现模型工具、独立会话、20／40、缓存、结果不足和恢复，以及本地浏览器 provider。provider 可选 unconfigured 或 browser，browser 可选 Bing／DuckDuckGo。当前正式配置为enabled=true、provider=browser、engine=bing；Schema缺省仍为关闭／未配置。Koishi已配置Puppeteer，本机Chrome已静态查到；用户启动／重启且服务就绪后才创建故事实例。见[配置启用记录](../records/feature-enablement-20261010/README.md)。

浏览器搜索一页返回候选，再读目标完整正文；候选标题／摘要不当正文。article/main还需非纯链接、非仅标题的正文证据，结构性status加载壳继续等待；短正文不加字数阈值。正文按 article、main、Readability 提取，不无条件使用整页 body；导航、页脚、验证／登录壳不能冒充正文。动态主体和页面内导航切换共用原操作时限。旧 webSources 不作兜底；不调用 DeepSeek 原生搜索或付费 API，没有隐藏翻页、换引擎、RSS 或重试。

provider 的 read 返回必填 `bodyFormat:'text'`，正文已在适配边界转换为纯文本。`normalizeMaterial` 仅正规化空白、URL并计 Unicode codepoint，不剥标签、不再次解实体；HTML来源必须显式先调用 `htmlToWebText`。DOM中的比较式、泛型、字面标签和实体文字因此原样保留，已有材料不重新清理。每档正文候选在清理后筛选证据，只拼接没有同档有效祖先的顶层子树，按DOM顺序保留；兄弟节点的真实重复文字不去重。

提取时先在仍连接的原DOM判断计算样式及祖先隐藏，再清理对应克隆；隐藏正文、访问墙、结果项和空态不作证据。存在可见凭据表单时去除登录区域（含标题和引导）；区域边界也必须依据清理后仍有真实正文的独立主体，空main、只有标题／链接或隐藏加载内容不作豁免。只有区域外独立正文才能解除登录墙。当前提取器版本dom-v3/readability-0.6.0。独立验收脚本启动默认等待60000ms，服务失败或未就绪也会清理并落盘失败；该启动预算不改变产品页面预算。见[修复交付](../records/image-search-post-review-fixes-20261010/DELIVERY.md)。

所有阶段共用本实例页槽，默认同时分配读取页的上限1、每次页面操作60000ms，含排队、建页、导航及主体等待。取消可先返回，但直到迟到 factory 和真实 close 结算才释放资源；无法证明已关闭则阻挡继续分配／实例替换。只关闭本插件自有页面；该页产生的popup关闭也纳入同一预约的排空，关闭失败且无法证明消失时不得释放预约。

真实公开验收：Bing 返回候选并读取中文／英文目标正文；合成动态／登录页另行验证。DuckDuckGo 当时返回验证码，保留失败报告，不自动绕过或切换。见[搜索交付](../records/local-browser-search-20261009/DELIVERY.md)。这不是现实新闻质量或模型搜索续调用的在线验收。

## 2. 谁可以使用

普通／共同主叙事，聊天／生活／共同个人导演，表达，基础记忆，深度整理／审核，世界，校园／课题组／周阶段、素材描述以及用户图观察均可在已启用且需资料时使用。用户图观察只核实公开对象，不借搜索猜图中文字或用户意图；没有必需通知而免调用的周阶段不额外搜索。

只有本轮搜索工具确实可用时，程序附加导演软提示：世界导演建议先查阅当日／最近24小时的重要公共新闻，核对来源与报道时间后决定粗粒度环境变化；聊天／生活／共同个人导演可按生活、兴趣或交流需要主动查阅，不必等用户提出搜索。不是强制每轮搜索或必须制造事件；查不到可未知、空变化，搜索不等于亲历。工具关闭、供应商不可用或配额耗尽时不附此提示。本人查阅进入记忆的资格仍按§6，不因提示扩大。

程序限制提供给阶段的资料可见范围；查询文字由模型生成并传给供应商，提示要求只用该阶段已可见信息，当前没有逐词检查查询的程序过滤器。表达搜索只核验／润色既定内容；维护搜索不能扩大正式记忆来源。网页正文始终是外部参考，不是改职责的指令。

## 3. 20成功／40失败口径

一次逻辑任务会话最多20次成功取得正文、40次失败，分开计数，任一达到上限停止新操作。不是每发一个搜索请求就重置20／40，也不是单个HTTP请求最多20页。

同一阶段的格式修补、本地查询续调用、多个搜索／读取调用和恢复共用原计数。下一阶段、下一故事轮或新的独立后台任务有自己的额度。计数表示取得页面材料和失败步骤，不是费用或网络调用总数。

- 成功：该阶段首次取得一份有效正文，包括首次从本轮公共缓存取得；同阶段重用同一页面不再加1。
- 失败：搜索异常、没有候选、非法候选URL、正文读取异常或空正文等；分别累计，不占成功额度。
- 失败未到40且成功未到20，可继续尝试其他候选或新查询。
- 达到失败40，即使成功不足20也停止；达到成功20同样停止。

候选列表去重复后逐页尝试。搜索请求可以要求多个成功页面，失败继续补尝试直到满足、候选耗尽或到限；不能以“一页失败”为由禁止剩余额度内继续查询。

## 4. 缓存B

本轮／同一任务主体可以复用公开页面缓存以减少实际网络读取，但阶段额度仍独立。同页在主叙事、个人、表达、记忆阶段各首次取得，会各计一次成功。一个实际抓取可对应多个阶段成功取得记录。

这是已确认的B口径：“每阶段能读多少页”，不是“每轮访问网络多少次”。状态同时记录缓存命中、供应商搜索次数和读取次数，避免把成功额度当HTTP收费数。

同一阶段重放已确认操作不重复计数。缓存不是本进程全局免费资源；任务结束释放该主体缓存，已保存阶段资料仍支持恢复。

## 5. 结果不足与未知

返回实际成功正文、要求／取得页数、累计计数和停止原因。少于要求时明确传回“结果不足”，不伪造资料或自动改用未配置网页。

模型可根据已有材料完成工作、保留未知或继续额度内查询。对话个人导演可以自然向用户询问，角色不必每个问题都得出确定答案。额度耗尽后收回工具，要求用当前材料输出自身合法结果。

正文去除明显页面框架后作为完整正文提供，没有12000字／网页token人工截断。页面数量有限仍可能撞模型实际容量；超限按报错保留，不自动摘要或删资料。

## 6. 实际提供与本人阅读

取得正文与成功提供给模型是两步。只有接口成功返回、相关正文确实进入该阶段后，才登记已提供；失败请求不谎称读过。

世界／学校可引用URL限定为其实际提供正文的地址，不从候选标题、查询或模型臆造链接中建立引用。报道和不确定内容保留其性质。

只有自主生活个人导演的实际提供产生本人查阅来源；有回复换代合同的轮，仅最终实际使用的personalRunId可作为本轮来源，可记录“我查到……”类短期及有依据感受，单独引用它无需新用户聊天。仅此来源不能变更私人细节或唤醒长期，也不能把网页中的他人事件写成亲历。

聊天／共同个人导演目前没有同等独立本人查阅登记；它们实际产生的正常公开输出或主叙事经历仍可作为普通记忆来源。不能概括成“所有个人导演搜索直接写入记忆”。

## 7. 中断与恢复

阶段、操作、已确认页、计数及模型工具检查点持久保存。中断后同一阶段接续，已确认步骤不重计；未确认操作可能重新执行，不能保证供应商实际请求绝对一次。

已经冻结剧情／发送的恢复不重新搜索来改稿。同输入的未发送恢复仍沿用同阶段工具进度和权限；新普通业务重新选择则使用reply:generation:stage:taskName阶段身份，旧lookup、修补及工具正文不自动注入。新代际各阶段有独立20／40额度，同代际失败／重启不重置。旧业务checkpoint在改绑事务压缩，计数／操作／材料／来源保留，incoming_image阶段不在该清理范围。主体公开缓存仍可显式复用，首次命中新阶段计一次成功。阶段完成后压缩检查点，保留需要的来源与统计。后台维护准备失败／停止保留完整阶段进度，只有最新持久任务 ready／done 才压缩，见[恢复§7](REMAKE_V0.5_RECOVERY.md#7-后台记忆恢复)。

Bing 的公开页面可达性／正文读取和资源排空已做独立验收；真实模型工具续调用、全部网站可达性和正式长期运行未验收。公开网页验收不发送角色背景、聊天、图片或密钥。

## 8. 状态展示

普通状态使用SQL历史汇总及当前最多3个任务、每任务6个阶段，展示各会话自己的20/40额度。后台整理及环境准备／待提交步骤也作为当前任务；状态不读正文、输入和checkpoint，不删除历史。网页状态通过有限条目与标签长度保持摘要有界，2048字符是该网页摘要的验收上限；完整诊断保留精确计数。环境跨generation继续用同一step owner和generation阶段键，保留累计计数、操作与材料；本地补查请求及pending状态可持久接续，实际返回依据与结果一起确认。它不是页面正文或模型输入预算，也不约束其他状态栏目。历史SQL汇总仍可能随会话数量增长，未新增全局持久计数缓存。
