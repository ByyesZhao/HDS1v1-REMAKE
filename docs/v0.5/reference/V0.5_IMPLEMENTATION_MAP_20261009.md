## 2. 部署与结构

当前为Koishi插件，HDSI故事处理在一个插件进程内，SnowLuma提供QQ接入；模型任务不是各自独立服务。Koishi位于`D:\HDSI-remake\runtime`，SnowLuma独立于`D:\SNOWLUMA`，两个根目录cmd由用户手动启动。当前OneBot采用正向WebSocket：HDSI连接SnowLuma的`ws://127.0.0.1:3001/`；Koishi控制台端口5141。此前反向配置与SnowLuma默认服务方向不匹配，已修正本地配置；用户重启后确认管理命令正常回复，见[首次连接排查与运行核对](../records/onebot-connection-20261010/README.md)。用户随后已确认普通聊天正常回复；图片与实际网页操作的在线质量没有由本次文档核对验证。
