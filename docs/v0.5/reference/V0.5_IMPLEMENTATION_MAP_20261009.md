## 2. 部署与结构

当前为Koishi插件，HDSI故事处理在一个插件进程内，SnowLuma提供QQ接入；模型任务不是各自独立服务。Koishi位于`D:\HDSI-remake\runtime`，SnowLuma独立于`D:\SNOWLUMA`，两个根目录cmd由用户手动启动。

SQLite使用JSON行及部分表达式索引、事务和WAL，保存正式角色、输入／输出、故事轮、经历、任务、记忆／细节／常驻、环境／学校、网页会话和后台任务。编译结果`lib/`由现有构建生成，数据库不因文档V0.5改名或新建。

## 4. 模型任务与强度

代码提供12个故事／后台连接键，加单独看图描述连接；固定信息审核的运行任务名为`memory_audit`，复用`memory_consolidation`连接，不能误报成新增独立连接。当前本地各连接均Flash，后续可分别换Pro。

| personal_life | deepseek-flash | low |
| personal_shared | deepseek-flash | low |

记忆`memoryEmbedding`与素材`embedding`当前都是`qwen3.7-text-embedding`、1024维，但连接和索引用途独立。该名称是当前本地实际配置，不是本次对供应商最新产品的推荐或新在线验证。

## 6. 用户概括与真实行为的差异

| 概括 | 当前实现 | 文档处理 |
| --- | --- | --- |
| 自主推进算一个导演 | 程序触发普通主叙事＋生活个人导演 | 放调度，保留两个模型职责 |
| 旁白中枢负责旁白 | 原称谓实际是调度；公共旁白来自共同主叙事 | 采用“调度中枢（原旁白中枢）” |
| 七天后才总结长期 | 每轮已经建立预备简要长期，后台可精炼 | 解释预备、生效与到期清理 |
| 固定信息一确定不能变 | 作者核心不自动改；细节可凭真实变化更新 | 区分作者背景、detail、learned和审核报告 |
| 3次／30次唤醒 | 同规范事件、同上海日期去重；30只进入审核候选 | 明写不同有效日期和三次续期组 |
| 所有个人导演网页直接记忆 | 独立self_web_read仅personal_life | 不扩大已有资格 |
| 单次搜索20／40 | 同逻辑阶段所有工具／修补／恢复累计 | 明确会话、缓存B和网络请求另计 |
| 双方无消息代写 | 程序依据本轮新用户输入集合，角色上轮输出影响计时 | 给出实际资格，避免称另有双方检测器 |
| 无输入不能重大代写 | 已确认允许活动内关键行动，不允活动外重大承诺 | 保留公开和非现实稳定属性边界 |
| 中断退回上一步 | 无尝试可再生；有尝试冻结续发；输出完续后处理 | 分阶段恢复表 |
| 只修错误字段 | 带错误说明／旧结果／Schema重返完整JSON | 不声称局部字段修复器 |
| 睡醒必定满体力 | 主叙事评估，无程序强制／专门必满提示 | 明确未实施 |
| 睡眠预约无条件发生 | 夜间／次晨预约安排可提前醒，普通睡眠仍有门禁 | 不把到期当自动越权 |
| 表达有专门可爱审核 | 单表达模型按风格润色，没有另一语气审核器 | 说明现状，不新增模型 |
| 所有活动不进四段 | 共同整体排除；自主内部经历排除，实际普通公开消息可入 | 分消息与经历 |
| 所有幕后工作空闲15分钟后 | 深度整理／审核等待；向量准备和机械清理不同门禁 | 不混同索引／清理／重整理 |

本轮只修文档。上表不把未实施的概括偷偷改成新需求，也不生成必须执行的新开发待办；若用户以后选择改变，再单独定规则。

## 7. 检索和服务边界

已实现记忆语义索引、直接键／词法／语义融合代码，但当前标定文件`calibration.semantic=null`，实际查询关闭纯语义路线；不会无收益地仍编码所有查询。词法标定文件也不是大规模真实供应商召回验收。

世界／学校模型能使用搜索接口；正式入口尚未装配供应商，webSearch=false。世界公共参考没有学校式逐事件知情台账。具体背景用途已批准启用，作者事实迁移未做。

目标私聊目前只接文本；新图描述为显式素材工具，非用户图片自动理解。图库已兼容，真实QQ持续收发、新图描述、现实新闻搜索与数月运行仍不能写成已通过。
