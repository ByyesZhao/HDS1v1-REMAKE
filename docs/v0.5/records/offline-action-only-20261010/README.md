# 动作表达限定在线下共同活动

起点：`008ca2c`。用户明确要求：普通聊天、主动联系和线上共同活动不公开 `【动作：…】`；线下共同活动中双方动作继续传给共同主叙事。本次是现有动作通道的边界修正，不新增动作解析器或模型连接。

## 规则与接点

- 个人导演的动作意图只允许用于本轮线下表达；本轮确认进入线下活动可有动作，线下末轮仍可在结束标志之前表达动作。确认进入线上活动则只允许文字。
- 表达合同由程序按实际输出模式选择：线下允许text/action，其余只允许text；不允许把动作标记塞入文字绕过限制。失败沿既有两次格式修补，不静默丢动作或冒充用户已看到。
- 权限由程序合同判定，表达提示只说明已选格式；普通主叙事仍只补过去生活，线上共同主叙事仍能公开虚拟活动剧情 `【…】`。`【动作：…】`不再作为线上动作输出通道。
- 用户线下动作原文和已确认角色动作继续进入本场获准原文，供后续共同主叙事和个人导演理解。普通／线上输入不新增语法解析器或强制删除文字。
- 已确认消息保留，已尝试发送的旧冻结轮仍按既有恢复合同完成；新生成／未尝试回退重算使用新合同。此次不升级数据库。
