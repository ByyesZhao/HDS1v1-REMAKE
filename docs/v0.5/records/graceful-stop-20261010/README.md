## 使用与边界

建议双击根目录stop-hdsi.cmd。停止窗口会等待，HDSI控制台打印等待及完成状态；收到成功响应后才显示停止完成。此期间保留控制台。没有运行实例／停止入口未就绪会提示，无强制结束。

Ctrl+C已加Koishi exit钩子等待，但Windows控制台父进程及直接关闭窗口的行为不作为可靠保证，首选停止文件。任务管理器强制结束、断电仍沿现有持久化恢复合同。等待新消息的15秒／60秒计时、未来预约和未开始的导演链不等；发送未知结果仍保留原重试规则，未承诺QQ绝对不重复。
