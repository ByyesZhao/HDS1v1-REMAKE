测量日期：2026-10-11。基线为只读归档源码 `9c20a97`（产品与审核 `ce7e88e` 相同），after 为 `69147f9`。同机 Windows / v24.21.0、相同依赖；测量窗口内暂停并行测试和产品源码编辑，原运行服务状态未改变，未声称专用空闲机器。正式库、私有配置与真实供应商均未使用。

每个档位保存七个独立同状态样本；除任务调度探针按其合同直接运行七次外，其他探针先预热一次。夹具创建与清理不计时。网页两版本交替运行，其余分别运行。源文件／探针哈希、样本与单位见JSON；时间只描述这些合成夹具，不外推长期生产表现。after/before越小表示本次中位耗时越少。W7生命周期接线发生在此测量之后，后续相关确定性预算由最终联测核对。

未标定build/freeze向量读取由4,096,000字节降到0，provider/query均为0；已标定路径仍读取4,096,000字节、调用1次查询和离线provider。没有为加速减少必要正文。未标定冻结序列化量在128字档为3111373→1042636字节，在4096字档为11047373→8978636字节。

这些中位数均未退化。长正文的build/freeze仍需完整读出、构造与序列化上下文，因而仍明显受字数影响；策略元数据查询也需SQLite读取JSON页、提取字段，并非恒定时间。已标定语义保留同样向量与排名工作，耗时变化很小，不能据此宣称语义查询明显加速。
