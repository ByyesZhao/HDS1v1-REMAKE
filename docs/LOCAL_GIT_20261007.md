# 本地 Git 仓库

2026-10-07 按用户要求在 `D:\HDSI-remake` 初始化本地 Git，默认分支为 `main`，首次提交保存当前源码、测试、实施与审核文档、依赖锁文件、启动脚本及旧项目参考资料。

仓库未设置远程地址；此次只在本机提交。未配置已有提交身份，仓库使用 `HDSI Local <hdsi-local@localhost>`，不修改全局 Git 配置。以后可用 `git config user.name "你的名字"` 和 `git config user.email "你的邮箱"` 修改本仓库的后续提交身份。

`.gitignore` 排除密钥、角色原始设定、本地部署配置、数据库与运行数据、依赖、编译输出、缓存、日志和实施备份。文件仍保留在原处，运行方式不变。Git 保存的是程序及文档版本，不承担运行数据库或密钥的备份。

检查状态使用 `git status`，后续保存修改可执行 `git add .` 与 `git commit -m "修改说明"`。若将来迁移到另一个目录，需要单独复制被忽略的本地配置和运行资料，并按 README 安装依赖、构建程序。
